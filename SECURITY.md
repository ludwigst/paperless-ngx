# Security Policy

## Reporting a Vulnerability

Report security issues through this repository's GitHub Security Advisory tab:

https://github.com/ludwigst/paperless-ngx/security/advisories/new

Please include:

- A clear description of the issue
- Affected version(s)
- Required configuration or permissions
- Reproduction steps
- Impact

Do not use the advisory channel for support questions, feature requests, or general bugs.
